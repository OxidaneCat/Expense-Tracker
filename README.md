# Expense Tracker 

A expense tracker that track expenses in different category.

Ciel

## Description
 - A expenses tracker thar allows the user to track expenses, categorise expenses, and record total amount spent.

## How to Run
 - Follow instructions in the terminal by typing available options at the prompt and press Enter.

## Features
 - Add expenses with date, name, cost, and categories
 - Option to remove specific expenses, remove all expenses, and remove all expenses in a category
 - View all expenses
 - View expenses in ther category
 - View total expenses cost
 - View total expenses cost in a category
## Challenges
Communication problems - Since we are working at the same time, when a teammate built their work on an outdated version of the code, the previous code updates were unintentionally removed by github. Therfore, we improved our communication by informing each other before merging, and we manually review the files and resolve merge conflicts. We enjoy collaborative coding since we can find and fix bugs faster together, and it also allows us to share interesting ideas to improve this program.
